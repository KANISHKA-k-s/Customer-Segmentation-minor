# Customer Segmentation using K-Means Clustering

##  Objective
Group customers based on purchasing behavior to improve marketing strategies.

##  Problem Statement
Businesses treat all customers the same and fail to identify valuable segments.

##  Proposed Solution
- Input: Customer data
- Output: Customer clusters

##  Technologies Used
- Python
- Pandas, NumPy
- Matplotlib / Seaborn
- Scikit-learn

##  Methodology
1. Data Preprocessing
2. Feature Selection
3. Elbow Method (optimal K)
4. K-Means Clustering
5. Visualization

##  Output
- Customer groups (clusters)
- Graphs showing segmentation
